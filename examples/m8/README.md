# Generated M8 configuration examples

These JSON files are sanitized examples generated by the same writers used by `validate.m8`:

```powershell
uv run python scripts/generate_m8_examples.py
```

They are committed so policy and configuration shape changes are reviewable and tested for drift.
They are deliberately not runnable authority: the VM id is all-zero and machine-local roots are
replaced by `${SKLAB_ROOT}`, `${SKLAB_REPO}` and `${PYTHON}`. Live runs continue to generate their
exact policy and config inside an ignored `runs/<id>/` directory; credentials, real VM identity,
boot identity, package paths and symbol locations must remain uncommitted.
